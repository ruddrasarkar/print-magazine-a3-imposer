# Print Magazine BD — A3 Imposer

## Run
1. Install Python 3.11+.
2. In Terminal:
   pip install -r requirements.txt
3. Run:
   python magazine_imposer.py

Put numbered pages in a folder:
1.jpg, 2.jpg, 3.jpg ... 24.jpg

The app sorts them naturally and creates an A3 PDF.

## Important
The current prototype is intended for testing the workflow. Before production printing,
verify duplex orientation, bleed, crop marks, paper grain, and your print shop's imposition
requirements with one physical proof.
